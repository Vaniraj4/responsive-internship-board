# Responsive Internship Board

A responsive full-stack internship portal that allows users to browse internship opportunities. The project includes a frontend, a Node.js and Express REST API, and a persistent SQLite database.

## Features

- Responsive interface for desktop and mobile devices
- Internship listings with title, company, domain, location, stipend, and duration
- Search and domain filtering
- REST API supporting Create, Read, Update, and Delete (CRUD)
- Pagination for internship records
- SQLite database persistence
- Request logging and API health check
- Input validation and structured JSON error responses

## Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd responsive-internship-board-github
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual repository URL.

### 2. Install backend dependencies

```bash
cd backend
npm install
```

### 3. Start the backend

```bash
node server.js
```

The API should run at:

`http://localhost:3000`

Keep the terminal running while testing the API.

### 4. Open the frontend

Open `index.html` in your browser, or use the VS Code Live Server extension if your frontend is configured to run that way.

## API Documentation

Base URL: `http://localhost:3000`

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | API homepage |
| GET | `/health` | Health check |
| GET | `/api/internships` | List internships |
| GET | `/api/internships?page=2&limit=2` | List internships with pagination |
| GET | `/api/internships/:id` | Retrieve one internship |
| POST | `/api/internships` | Create an internship |
| PUT | `/api/internships/:id` | Update an internship |
| DELETE | `/api/internships/:id` | Delete an internship |

### Internship data model

| Field | Type | Required |
|---|---|---|
| id | Integer | Generated by database |
| title | String | Yes |
| company | String | Yes |
| domain | String | Yes |
| location | String | Yes |
| description | String | No |
| stipend | String | No |
| duration | String | No |

The database uses SQLite. The schema is initialized by `src/db.js`.

### Example POST request

URL: `http://localhost:3000/api/internships`

Method: `POST`

Content-Type: `application/json`

```json
{
  "title": "Backend Developer Intern",
  "company": "Demo Technologies",
  "domain": "Web Development",
  "location": "Hyderabad",
  "description": "Learn Node.js and Express",
  "stipend": "15000",
  "duration": "3 months"
}
```

Expected successful status: `201 Created`.

### Pagination response

A successful list response contains:

- `success`: indicates whether the request succeeded
- `data`: array of internship records
- `pagination.page`: current page
- `pagination.limit`: records requested per page
- `pagination.total`: total records
- `pagination.totalPages`: total available pages

### Error responses

The API uses appropriate HTTP status codes, including:

- `400 Bad Request` — invalid input
- `404 Not Found` — internship or route not found
- `500 Internal Server Error` — unexpected server error

## Security Considerations

- Validate incoming API data.
- Use parameterized SQL queries.
- Avoid exposing internal error details to API clients.
- Configure CORS for trusted origins before production deployment.
- Keep dependencies updated.
- Do not commit credentials or secret keys.
